# DSH Codex reasoning effort slider

你是否认为 DeepSeek Harness 原版的推理调节过于简陋？

你是否因为用不起昂贵的 Astra 而感到遗憾？

没关系，本插件将 Codex 桌面版的推理深度调节滑块 1:1 迁移到了 DeepSeek Harness！

这样你就可以拉满推理强度并打开 Fast（无实际作用），然后请神鲸来帮你预测未来了（doge）。

> Fast 模式仅改变视觉动画，既不会让模型加速，也不会改变实际用量。Ultra 推理挡位对应 Deepseek 的 `max` 推理等级。

## 安装方法

支持 DeepSeek Harness Desktop **0.2.0-rc.2 及以上版本**，仅在 Windows 11 + 0.2.0-rc.2 上实测通过，其他设备与更高版本有待测试。

通过 Harness 官方的插件管理页面安装，无需命令行：

1. 在本仓库下载插件
2. 打开 DeepSeek Harness，点击侧边栏的 **插件 → 添加插件**。
3. 在安装输入框中粘贴插件文件夹的**完整路径**，不是 ZIP 文件或 `package.json` 文件的路径，或是粘贴本仓库的地址。
4. 阅读并勾选信任确认，点击 **安装**，完成后点击 **立即启用**。若提示需要重启，按提示重启 Harness。
5. 点击会话输入栏下方的模型名称，若展开推理强度滑块则安装成功。

安装后不要移动或删除插件文件夹。

## 更新与卸载

修改插件文件后，彻底退出并重新打开 Harness，即可加载更新。

发布版本更新时，在 **插件** 页面卸载旧版本，再通过 **添加插件** 安装新版本并启用。

卸载时，打开 **插件** 页面，找到 **DSH Codex reasoning effort slider**，进入详情后点击 **卸载** 并确认。只想暂时关闭时，关闭插件的启用开关即可。
